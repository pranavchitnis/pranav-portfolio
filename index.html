Projects & Technical Exploration

01 · Web development

AFTERHOURS — Real-Time Watch Party Platform

Developed an interactive web application that enables friends to watch videos together remotely. AFTERHOURS creates a shared viewing environment by combining synchronised YouTube playback with real-time communication and collaborative activities. The project explores how web technologies can be used to create engaging, interactive experiences for multiple users.

Building AFTERHOURS involved designing an interactive interface, integrating Firebase Realtime Database, and coordinating shared application states across users. It also provided an opportunity to explore real-time data handling, collaborative features, and the challenges of creating a consistent experience for everyone in a shared room.

Focus: HTML, CSS, JavaScript, Firebase Realtime Database, interactive web development, and real-time synchronisation.

02 · Data science

Weather Prediction Model

Developed a Python-based weather prediction model to explore how historical observations and recurring patterns can be used to estimate weather conditions. The project introduced me to the fundamentals of data-driven prediction and the process of using past measurements to identify relationships that may help explain future outcomes.

Working on this project encouraged me to think about how data is collected, interpreted, and applied to practical problems. It also provided an introduction to the challenges of predictive modelling, including recognising patterns in historical data and understanding that predictions are estimates rather than guaranteed outcomes.

Focus: Python, Data Science fundamentals, predictive modelling, weather data, and analytical problem solving.

03 · Physics simulation

Projectile Motion Simulator

Developed a Python-based simulation to model projectile motion and visualise the trajectory of an object under the influence of gravity. The project explores how variables such as initial velocity and launch angle influence the motion of a projectile, connecting mathematical equations with observable physical behaviour.

By translating the underlying equations into a computational model, I explored how changes in initial conditions affect a projectile's maximum height, horizontal range, and overall trajectory. This project strengthened my understanding of classical mechanics and demonstrated how programming can make abstract scientific concepts easier to investigate and visualise.

Focus: Python, classical mechanics, mathematical modelling, motion simulation, and scientific visualisation.

04 · Data visualisation

Weather Data Visualiser

Developed a Python-based data visualisation project to represent weather measurements through charts and graphical displays. The project focuses on making numerical weather data easier to interpret by highlighting changes over time and presenting observations in a more accessible visual format.

Exploring weather data through visualisation helped me understand how graphs can reveal trends, fluctuations, and potential relationships that may not be immediately apparent from raw measurements. It also complemented my work on weather prediction by emphasising the importance of exploring and understanding a dataset before drawing conclusions from it.

Focus: Python, data handling, data visualisation, exploratory data analysis, and interpreting real-world datasets.

05 · Computational exploration

Python-Based Physics Modelling

Explored the use of Python to represent physical concepts through mathematical models and computational experiments. This work involves translating physical relationships into code and examining how a system's behaviour changes when its parameters or initial conditions are modified.

By combining mathematical reasoning with programming, I aim to develop a deeper understanding of the principles behind physical phenomena and their practical applications. Computational modelling also provides a way to test ideas, visualise theoretical relationships, and investigate scenarios that may be difficult to explore through equations alone.

Focus: Python, physics, mathematical modelling, computational experimentation, and scientific problem solving.
